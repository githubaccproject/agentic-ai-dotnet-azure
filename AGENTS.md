# TelecomIQ repository guidance

- Read [the Codex handoff](docs/codex-handoff.md) before continuing the project. It records the verified baseline, open checks, and planned milestones.
- Use [development connectivity](docs/dev-connectivity.md) for local configuration, Azure roles, and smoke tests. Inspect the current checkout and actual run evidence before changing that status.
- Use only fictional documents. Keep credentials, tokens, and real company or customer data out of the repository and logs.
- Use GitHub Actions for Azure operations. Keep Azure Free Trial spending limits enabled and obtain approval before creating additional billable resources.
- Verify changes in small batches. Update the progress notes with the observed result and distinguish local checks from live Azure verification.
